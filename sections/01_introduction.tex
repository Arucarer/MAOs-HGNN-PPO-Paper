\section{Introduction}
%【章节标题译文】
% 引言
\label{sec:introduction}





%【第 1 节｜第 01 段｜1-P01】
The production of complex equipment requires close coordination between component processing
and multi-level assembly. Components follow prescribed technological routes on shared machines,
while each assembly can begin only when its required components or subassemblies are available.
Flexible machine assignment and component matching provide alternative ways to organize production,
but also couple resource allocation with assembly synchronization. The flexible job shop scheduling problem
with multi-level assembly operations (FJSP-MAOs) captures these dependencies within a common scheduling
model \cite{ning2027fjspmaos}. Maintaining this coordination when production conditions change is
essential for completing products efficiently.

% 而每项装配只有在其所需的零部件或子装配体均已就绪后才能开始。柔性机器分配与零部件匹配为生产组织提供了多种选择，
% 同时也使资源分配与装配同步相互耦合。具有多级装配工序的柔性作业车间调度问题（FJSP-MAOs）在统一的调度模型中刻画了这些依赖关系~\cite{ning2027fjspmaos}。
% 在生产条件变化时维持这种协调，对于高效完成产品生产至关重要。

%【第 1 节｜第 02 段｜1-P02】
This coordination becomes particularly challenging under processing-time variations, machine failures,
and urgent order arrivals. These events change operation durations, resource availability,
and the set of production tasks, respectively. Their consequences extend beyond the directly affected operations:
a delayed component may postpone a subassembly and subsequently delay higher-level assemblies,
while an urgent order may compete with existing tasks for the same machines. Reactive adjustments must
therefore account for both local resource conditions and downstream assembly requirements.
Frequent changes to an existing schedule can also disrupt planned operation sequences and machine assignments.
This study consequently considers two competing objectives: minimizing makespan and minimizing deviation
from the baseline schedule.

% 其后果并不局限于直接受影响的工序：某个零部件的延误可能推迟子装配，进而延误更高层级的装配；

% 频繁修改已有调度计划还可能打乱原定工序顺序和机器分配。基于此，本文考虑两个相互竞争的目标：

% 过度调整又可能破坏已有安排，因此兼顾效率与稳定性。






%【第 1 节｜第 03 段｜1-P03】
A central difficulty is how to represent the changing production state for online decision-making.
Aggregate shop-floor statistics alone do not explicitly distinguish technological precedence,
machine competition, component membership, and assembly readiness. Graph representations can preserve these relationships,
but retaining graph connectivity alone does not determine which relationships matter most at a given decision epoch.
In particular, the relevance of different processing--assembly paths depends on the current disturbance
and on whether the decision concerns machine routing, operation sequencing, or failure recovery.
The representation problem is therefore to identify decision-relevant information across heterogeneous
dependencies and update its importance as production evolves.

To address this problem, this paper extends the FJSP-MAOs to reactive scheduling under the three disturbances
and develops a dynamic heterogeneous graph-based rule-selection method. An event-driven environment
updates the observable production state, which is encoded by a heterogeneous graph neural network (HGNN).
Meta-path semantic attention adaptively weights processing--assembly information,
and decision-specific readout extracts state representations for the scheduling roles.
Three proximal policy optimization (PPO) heads select rules for machine routing, operation sequencing, and failure recovery
\cite{schulman2017ppo}. The selected rules then generate concrete decisions from the
corresponding feasible sets. PPO and the three decision heads provide an established learning and execution interface; the methodological focus is the state encoder. The main contributions are summarized as follows:
